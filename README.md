# PuppetForge

브라우저에서 실행되는 개인용 2D 종이인형 애니메이션 제작 툴.

한 장짜리 PNG 캐릭터에 관절을 찍고 영향 영역을 칠한 뒤, 범용 애니메이션을 입혀
게임에서 바로 쓸 수 있는 가벼운 애니메이션 데이터를 만드는 것이 목표다.
자세한 내용은 [기획서](./범용%20웹%20종이인형%20애니메이션%20툴%20개발%20기획서.md)를 참고한다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
npm test         # 코어 로직 테스트
```

Chromium 계열 브라우저 + WebGL 환경을 기준으로 한다.

## 현재 상태 (v0.11.0)

기획서 70의 Phase 1 · 2 · 3 · 4 · 5 · 6 · 8까지 되어 있다.
변경 내역은 [`VERSION.md`](./VERSION.md)를 참고한다.

- Vite + TypeScript + Phaser 기반 프로젝트 설정
- 한국어 편집기 레이아웃 (상단 메뉴 / 관절 · 속성 패널 / 애니메이션 바 / 편집 모드 탭)
- PNG · WebP 드래그 앤 드롭 및 `이미지 불러오기`
- 캔버스 Zoom(마우스 휠) / Pan(우클릭 또는 휠클릭 드래그)
- 관절 추가 · 삭제, 이름 · 부모 · 태그 · 강도 · 4가지 변형 방식 편집
- 41개 태그를 묶음별 버튼으로 붙이고 뗀다. 마우스를 올리면 설명과
  "이 태그를 쓰는 동작" 목록이 뜬다. 변형 네 가지도 버튼 + 툴팁으로 고른다
- Soft(부드러운 움직임), Rigid(형태 유지), Pinned Soft(위치 고정·부드러운 경계), Fixed(완전 고정)를
  실제 Mesh 변형에 반영
- 캔버스에서 관절점을 직접 집어서 위치 이동
- 관절 목록 드래그로 순서 정리, `×`로 삭제
- 관절점과 부모 연결선 표시, 상단 우측에서 표시 항목 켜고 끄기
- 이미지 크기에 맞춘 격자 Mesh 자동 생성과 변형 렌더링
- 영향 영역 칠하기 — 수채화처럼 쌓이는 브러시와 지우개, 자동 정규화
  (크기는 실제 크기가 보이는 점 버튼 28단계, 가중치는 눈금 그래프로 조정)
- 가중치를 바꾸면 캔버스 브러시 커서의 진하기 · falloff와 크기 버튼의 점 진하기가 함께 바뀐다
- 칠하기는 이미지가 그려진 영역 안쪽에만 들어간다 (투명 배경 기준 클리핑)
- 촘촘한 점 패턴으로 영향 영역 표시, `전체 보기`로 빈 곳(움직이지 않는 곳) 한눈에 확인
- 관절마다 다른 색이 자동으로 붙고, 원형 팔레트에서 직접 고를 수 있다
- 프리셋 13종 — 기본 6(`대기` `이동` `피격` `사망` `점프` `포효`)과
  공격 계열 7(`공격` `물기` `할퀴기` `휘두르기` `찌르기` `몸통박치기` `캐스팅`). 전부 JSON 데이터다
- 애니메이션 이름은 더블클릭해서 자유롭게 바꾼다. 이 이름이 게임에서 부를 이름이다
- 하단에서 애니메이션을 넣고 빼고, `−`로 내보내기에서만 제외(숨김)
- 애니메이션마다 속도(0.1~3배) · 강도(0~2배) · 흔들림(0~2배)을 조절한다.
  값은 파일에 저장되어 게임까지 따라간다
- 따라 흔들림 — 꼬리 · 머리카락 · 망토처럼 `secondary` 태그가 붙은 부위가
  몸을 한 박자 늦게 따라 흔들린다 (Track 없이 런타임이 자동으로 만든다)
- `내보내기`: 숨기지 않은 애니메이션만 담은 `<이름>.export.zip`
- 프로젝트 저장 · 불러오기 (`character.puppet.zip` = puppet.json + 원본 이미지)
- Undo / Redo (`Ctrl+Z`, `Ctrl+Y` 또는 `Ctrl+Shift+Z`), 저장 `Ctrl+S`

아직 없는 것: 편집기 안에서 키프레임 만들기 · 고치기, 애니메이션 블렌딩,
IndexedDB 자동 저장, Runtime 패키지 분리, 스프라이트 시트 내보내기.
순서는 기획서 70을 따른다.

## 조작

| 조작 | 결과 |
| --- | --- |
| 이미지 끌어다 놓기 | 캐릭터 불러오기 (`.puppet.zip`이면 프로젝트 열기) |
| 좌측 `추가` | 고른 파츠의 관절을 화면 중앙에 생성 |
| 관절점 드래그 | 위치 이동 |
| 목록 드래그 / `×` | 순서 정리 / 삭제 |
| 휠 / 우클릭 · 휠클릭 드래그 | 확대 축소 / 화면 이동 |
| 우측 `칠하기` / `지우개` | 캔버스 드래그가 영역 편집으로 바뀜 (같은 버튼 다시 누르면 꺼짐) |
| 우측 색 견본 | 원형 팔레트에서 관절 색 고르기 |
| 우측 `+ 태그` | 태그 목록 펼쳐서 눌러 붙이기 (마우스를 올리면 설명) |
| 상단 우측 `전체 보기` | 모든 관절의 영향 영역과 빈 곳을 함께 보기 |
| 하단 이름 | 애니메이션 재생 |
| 하단 `+` / `×` | 프리셋 추가 / 목록에서 삭제 |
| 하단 이름 더블클릭 | 게임에서 부를 이름으로 바꾸기 |
| 하단 `−` | 내보내기에서만 제외 (파일에는 남는다) |
| 하단 `속도` · `강도` · `흔들림` 막대 | 고른 애니메이션의 속도 · 움직임 크기 · 따라 흔들림 조절 |

## 폴더 구조

```text
src/
 ├ core/            # 엔진 독립 로직 (렌더러 · UI에 의존하지 않는다)
 │  ├ format/       # Puppet JSON 타입, 상수, 생성 · 검증
 │  ├ skeleton/     # Bone 조회 · 계층 정렬 · 부모 변경 검사 · 스킨 변환
 │  ├ mesh/         # 격자 Mesh 생성
 │  ├ weight/       # 영향 영역 계산 · 정규화
 │  ├ animation/    # 키프레임 보간 · 태그 대상 찾기 · 재생
 │  └ physics/      # 따라 흔들림 (Secondary Motion)
 ├ editor/          # 편집기 전용 코드
 │  ├ ui/           # DOM UI
 │  ├ tools/        # 이미지 불러오기 등 편집 도구
 │  ├ state/        # 편집기 상태 스토어
 │  └ history/      # Undo / Redo
 ├ renderer/
 │  └ phaser/       # 편집 캔버스 (Phaser Scene)
 ├ main.ts          # 조립 지점
 └ style.css
tests/              # 코어 로직 테스트 (Vitest)
docs/               # 포맷 문서
```

## 설계 원칙

- 스켈레톤 타입(인간형 · 4족보행 등)을 만들지 않는다. 모든 캐릭터는 노드와 부모 관계의 집합이다.
- 애니메이션은 Bone 이름이 아니라 **태그**를 대상으로 한다. 없는 태그는 조용히 건너뛴다.
- Editor와 Runtime, Renderer와 Animation 로직을 분리한다.
- Puppet JSON이 단일 소스다. 엔진별 파일을 따로 원본으로 두지 않는다.

## 배포

`main` 브랜치가 갱신되면 Vercel이 정적 사이트로 자동 배포한다 (`vercel.json`).
서버와 데이터베이스는 사용하지 않는다.
